The Shipment API lets you manage outbound shipment records in Tilroy, supporting home delivery workflows where your warehouse needs to confirm dispatch and track shipping status. When a home delivery order is ready to leave your warehouse, use this API to record the shipment and keep Tilroy's order state up to date.

## Use Case: Home Delivery Orders

Home delivery (HD) orders in Tilroy represent a commitment to deliver goods to a customer's address. Once your warehouse picks, packs, and ships the goods, you need to record that dispatch back in Tilroy so the order lifecycle reflects the actual fulfillment state.

The Shipment API is the mechanism for doing exactly that — creating and managing the shipment records that mark HD order lines as dispatched and communicate shipping details back to Tilroy.

<Tip>
  Home delivery dispatch involves more than just the Shipment API. For a complete picture of the HD order fulfillment flow, also review the **Transfer API** (particularly the `doDispatch` flag for automatic dispatch handling) and the **Order API** for order lifecycle management. The three APIs work together to support end-to-end home delivery fulfillment.
</Tip>
